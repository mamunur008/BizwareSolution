# Bizware Solution website

A static, responsive, company website with enterprise-tech dark styling, optional light mode, SalesTrace showcase, six services, data engineering capabilities, leadership and Netlify contact form.

## Preview locally

From this folder, run `python -m http.server 8000`, then open http://localhost:8000 . No build or npm install is required.

## Deploy to Netlify

Drag this **entire folder** into a new Netlify project's manual deployment area, or commit the contents to a dedicated Git repository connected to Netlify. Ensure form detection is enabled. Configure form submission notification email in Netlify's Forms settings. Test submissions on the deployed site.

## Edit
- `index.html`: company copy, services, SalesTrace, leadership, address and form
- `style.css`: dark/light design, layout and responsiveness
- `script.js`: theme, navigation, animation and form submission
- `assets/habib-tarafder.png`: supplied leadership photograph

No client identities, historical employer names, fabricated metrics or unverified contact details are included. The illustrated product mockup is labeled as a concept, not a screenshot.
